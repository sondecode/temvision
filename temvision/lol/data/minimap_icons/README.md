# Minimap Icon Templates

Place champion icon PNG files here for minimap detection.

Naming convention: `<champion_name>.png` (e.g., `Jinx.png`, `Zed.png`).

Recommended size: 24×24 or 32×32 pixels, cropped from the in-game minimap.

To extract icons:
1. Take a screenshot during a game
2. Crop the minimap champion icons
3. Save as PNG with the champion name
